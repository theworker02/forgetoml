# forgetoml

Forge HTML/Markdown toml fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/forgetoml/

## Install / run

```bash
git clone https://github.com/theworker02/forgetoml.git
cd forgetoml
node src/cli.js
node --test
```
